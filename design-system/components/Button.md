# Button

Tres variantes para acciones: primaria verde, secundaria con borde y fantasma azul como enlace.

- **Primario** (`dj-btn--primary`): una vez por vista, para lo que la página existe (“Descargar PDF”).
- **Secundario** (`dj-btn--secondary`): acciones alternativas (“Ver en GitHub”, “Copiar enlace”).
- **Fantasma** (`dj-btn--ghost`): navegación a otra lista (“Todos los recursos →”).
- Verbo primero, en minúscula salvo la primera letra. Sin signos de exclamación.
- El foco de teclado usa el token `focus`.
