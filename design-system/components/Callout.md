# Callout

Un recuadro con borde completo para destacar un consejo, un riesgo o un tema de seguridad dentro de un recurso.

| Variante | Clase | Cuándo |
| --- | --- | --- |
| Pro Tip | `dj-callout` | Un atajo o buena práctica. El más común. |
| Advertencia | `dj-callout--warning` | Un comando destructivo o irreversible. |
| Seguridad | `dj-callout--security` | Secretos, exposición, permisos. Solo para riesgo real. |

- Título corto en negrita (“Pro Tip”, “⚠ Cuidado”, “Seguridad”) y una o dos frases. Si necesita más, es una sección.
- Máximo dos callouts por sección; si todo está destacado, nada lo está.
- Borde en los cuatro lados, nunca solo una franja izquierda: esa franja es exclusiva del bloque de código.
