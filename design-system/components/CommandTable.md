# CommandTable

La tabla de referencia: cabecera azul, primera columna monoespaciada y filas separadas por una hairline.

- Para comparar (Windows vs Linux, modos de `reset`) o para listar opciones con su significado.
- La primera columna es el término que se busca (comando, flag, código de estado) en `heading` monoespaciado.
- Celdas cortas; si una celda necesita más de una frase, usa una lista.
- En móvil la tabla hace scroll horizontal dentro de su contenedor; nunca se parte un comando.
