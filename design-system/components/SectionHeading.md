# SectionHeading

Los títulos dentro de un recurso: h2 en azul `heading` con peso 300 y una hairline, y h3 en negrita.

- El h2 separa temas grandes (“Administración de redes”); el h3 nombra el bloque de código o tabla que sigue.
- Cada h2 genera un ancla para enlazar directo a la sección.
- No pongas dos h2 seguidos sin contenido entre ellos.
