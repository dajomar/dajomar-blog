# Tag

Dos piezas pequeñas: el tag de tema (píldora gris) y el chip de flag (azul, monoespaciado) para explicar opciones de un comando.

- **Tag** (`dj-tag`): temas de un recurso, en minúscula. Filtra la lista de recursos al hacer clic.
- **Flag** (`dj-flag`): solo para opciones de línea de comandos en una frase de leyenda, como en los cheat sheets: “`-t` TCP · `-u` UDP”.
- Ninguno de los dos indica estado (nuevo, actualizado); para eso, la fecha en la etiqueta de la tarjeta.
