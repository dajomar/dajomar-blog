Administración de redes

Para revisar la red de un servidor casi siempre sigo el mismo orden: interfaces, rutas, puertos y DNS.

Interfaces, IPs y rutas

bash
ip a                       # interfaces y direcciones IP
ip r                       # tabla de rutas / gateway
sudo ip link set eth0 up

Puertos y conexiones

bash
ss -tulpn                  # puertos en escucha + proceso
sudo lsof -i :443          # quién usa el puerto 443
nc -zv 10.0.0.5 22         # ¿puerto abierto?

-t TCP · -u UDP · -l escuchando · -p proceso · -n sin resolver nombres

Pro TipSi no hay internet, revisa en orden: ip a (¿tengo IP?) → ip r (¿tengo gateway?) → ping al gateway → dig google.com (¿falla el DNS?).

File system

En Linux todo es un archivo y todo cuelga de una sola raíz /. No hay letras de unidad: los discos se montan en carpetas, siguiendo el estándar FHS.

RutaQué contiene
/Raíz de todo el sistema
/etcConfiguración del sistema y servicios
/homeCarpetas personales de los usuarios
/varDatos variables: logs, caché, bases de datos
/tmpTemporales (se borra al reiniciar)
/usrProgramas y librerías instalados
/proc /sysVirtuales: información en vivo del kernel

Montaje automático

/etc/fstab
UUID=1234-abcd  /mnt/datos  ext4  defaults  0  2
⚠ CuidadoPrueba con sudo mount -a antes de reiniciar: un error en /etc/fstab puede dejar el sistema sin arrancar.
