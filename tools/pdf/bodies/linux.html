File System: cómo está organizado

En Linux todo es un archivo y todo cuelga de una sola raíz /. No hay letras de unidad (C:, D:): los discos se montan en carpetas. La estructura sigue el estándar FHS.

RutaQué contiene
/Raíz de todo el sistema
/bin /sbinComandos esenciales (hoy enlaces a /usr/bin)
/bootKernel y gestor de arranque (GRUB)
/devDispositivos como archivos (/dev/sda)
/etcConfiguración del sistema y servicios
/homeCarpetas personales de los usuarios
/rootHome del usuario root
/varDatos variables: logs, caché, bases de datos
/tmpTemporales (se borra al reiniciar)
/usrProgramas y librerías instalados
/optSoftware de terceros
/mnt /mediaPuntos de montaje manuales / USB
/proc /sysVirtuales: info en vivo del kernel y procesos
/srvDatos servidos (web, FTP)

Tipos de file system comunes

ext4El estándar en Debian/Ubuntu. Estable, con journaling.
xfsPor defecto en RHEL. Muy bueno con archivos grandes.
btrfsSnapshots, compresión y subvolúmenes (Fedora, openSUSE).
tmpfsVive en RAM, desaparece al reiniciar.
vfat / ntfsCompatibilidad con USB y Windows.

Journaling: registra los cambios antes de aplicarlos para recuperarse de apagones sin corromper datos. Inodo: ficha con los metadatos de cada archivo (dueño, permisos, bloques); el nombre solo apunta al inodo. Puedes quedarte sin inodos aunque haya espacio (df -i).

Discos, particiones y montaje

lsblk -f  # discos, particiones, FS y UUID
sudo fdisk -l
sudo mkfs.ext4 /dev/sdb1  # ⚠ formatea
sudo mount /dev/sdb1 /mnt/datos
sudo umount /mnt/datos
df -hT ; df -i            # uso por FS e inodos
sudo fsck /dev/sdb1       # reparar (desmontado)

Montaje automático en /etc/fstab

UUID=1234-abcd  /mnt/datos  ext4  defaults  0  2

Dispositivo · punto de montaje · tipo · opciones · dump · orden de fsck. Prueba con sudo mount -a antes de reiniciar.

Enlaces

ln -s /etc/nginx/sites-available/app \
      /etc/nginx/sites-enabled/
ln archivo.txt copia_dura.txt

-s Simbólico: acceso directo a una ruta (se rompe si se borra el original). Sin -s: enlace duro, otro nombre para el mismo inodo.
