Una IP privada no sale a internet directamente: el router hace NAT y la traduce a la IP pública.

Fórmula: hosts = 2(32 − CIDR) − 2. Se restan la dirección de red y la de broadcast.

Ejemplo: 192.168.10.70/26

Salto de bloque: 256 - 192 = 64
Redes: .0  .64  .128  .192
Red:        192.168.10.64
Primer host 192.168.10.65
Último host 192.168.10.126
Broadcast:  192.168.10.127
Pro Tip: Para cualquier máscara, el tamaño del bloque es 256 menos el último octeto que no es 0 ni 255. Las subredes empiezan en múltiplos de ese número.

TCP vs UDP

TCPUDP
ConexiónSí (3-way handshake)No
FiableReenvía lo perdido, en ordenNo garantiza entrega
VelocidadMás lentoMás rápido

Handshake: SYN → SYN-ACK → ACK. Muchos SYN sin respuesta suelen indicar un escaneo o un SYN flood.

Protocolos clave

DHCP entrega IP, máscara, gateway y DNS en 4 pasos (DORA): Discover → Offer → Request → Ack.

ARP traduce una IP a su dirección MAC dentro de la red local.

DNS traduce nombres a IPs. Registros principales:

A / AAAANombre → IPv4 / IPv6
CNAMEAlias hacia otro nombre
MXServidor de correo del dominio
TXTTexto: SPF, DKIM, DMARC, verificaciones
NSServidores autoritativos
PTRIP → nombre (DNS inverso)

Verificar

show ip interface brief
show running-config
show vlan brief
show interfaces trunk
show ip route
show mac address-table
show cdp neighbors

Access: lleva una sola VLAN (equipos finales). Trunk: lleva varias VLANs etiquetadas (entre switches y routers).

Pro Tip: Diagnostica de abajo hacia arriba: ¿cable o Wi-Fi conectado? → ¿tengo IP o es 169.254? → ping al gateway → ping 8.8.8.8 → nslookup google.com. Si llega al 8.8.8.8 pero no resuelve nombres, el problema es DNS.
